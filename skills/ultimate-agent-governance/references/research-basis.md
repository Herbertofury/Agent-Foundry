# Research Basis

This skill follows four evidence-backed patterns:

1. **Hierarchical repository instructions:** Codex, GitHub/VS Code, Gemini, Cursor, Cline, and Roo support repository or scoped instruction mechanisms.
2. **Progressive disclosure:** Agent Skills keep detailed workflow/reference material out of the always-on context until relevant.
3. **Behavioral evaluation:** real-harness skill evals and 2026 research show that skill adherence varies by agent/model, so inspection alone is not proof.
4. **Minimal context:** 2026 AGENTS.md research found that unnecessary context can reduce task success and increase inference cost.
