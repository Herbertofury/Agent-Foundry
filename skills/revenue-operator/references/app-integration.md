# App Integration

The companion Revenue Operator browser-extension app lives outside the skill ZIP and provides a local-first pipeline UI.

Use it as the user's visible operating console when available. Keep the skill's logic authoritative for current-market research and opportunity choice, while using the app for:

- ranked opportunity display
- proposal drafting and copy workflows
- pipeline state and stage progression
- received-revenue ledger
- storage-fund goal tracking
- JSON/CSV export

Do not claim an application was submitted or money was earned unless the external service confirms the action or the user records received revenue.
