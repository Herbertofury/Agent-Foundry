# Chat Skills Catalog

These nine flagship components are designed for chats, selected in ChatGPT or a compatible chat harness. They are separate from [coding-agent instructions](AGENTS-md-and-Invariants).

| Chat workflow | Purpose |
|---|---|
| Ultimate Agent Governance | Chat acceptance and governance authoring |
| Zero-Loss Chat Accelerator | Chat continuity, anti-stall and state reuse |
| Project Brain Orchestrator | Chat project identity, checkpoints and remote continuity |
| Minecraft Dev Kit | Minecraft development/conversions and runtime QA |
| Minecraft Repair | Bounded Minecraft diagnosis and repair |
| Project Visual QA Showcase | Visual QA and showcase artifacts |
| Artifact Browser Companion | Companion browsers for research artifacts |
| Revenue Operator | Paid-work and revenue workflows |
| Skill Creator | Creating and updating chat Skills |

[Source catalog](https://github.com/Herbertofury/Agent-Foundry/blob/main/catalog/SKILLS.md) links the eight mirrored packages. Skill Creator is externally supplied; its source is not included in current Foundry packages. Check actual installed availability.

The narrowest selected Skill owns procedure. Governance/Zero-Loss provide applicable overlays; Project Brain joins when project state matters. This composition applies within selected chats. It does not auto-install Skills, authorize external actions or impose chat workflows on repository agents.
