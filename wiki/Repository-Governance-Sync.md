# Repository governance sync

[Canonical adoption and evidence guide](https://github.com/Herbertofury/Agent-Foundry/blob/main/docs/REPOSITORY-GOVERNANCE.md)

One compact shared mindset is pinned by version and digest. Project instructions remain local, while AGENTS.md and CLAUDE.md route to the same managed core. Plan/status are read-only, edited snapshots conflict, and existing custom instructions are preserved. Skills remain on demand. Synchronization parity is not a claim of behavioral superiority.

Cross-repository rollout is tracked separately; the existence of this tooling does not mean every repository has adopted it. Legacy Engineering-Atlas and Feature-Foundry are migration sources, not new rollout targets.
