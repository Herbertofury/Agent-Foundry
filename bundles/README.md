## Publishing rule
For future bundles record:
- artifact name;
- semantic/version lineage when applicable;
- SHA-256;
- exact byte size;
- canonical durable location;
- validation status;
- source commit/checkpoint where available;
- supersession relationship to the previous bundle.

Do not create unexplained same-name duplicates.
