## Publishing rule
For future bundles record artifact name, version lineage when applicable, SHA-256, exact byte size, canonical durable location, validation status, source commit/checkpoint where available, and supersession relationship.

Do not create unexplained same-name duplicates.


## Trust roadmap

Future Agent Foundry releases should prefer:
- GitHub Artifact Attestations or an equivalent verifiable provenance record;
- source commit + workflow identity;
- SHA-256 and exact byte size;
- SBOM for code-bearing packages when useful;
- AgBOM-style inventory for complete agent distributions;
- security review/scan receipt for third-party content;
- deterministic or otherwise reproducible packaging inputs.
